📖 token 怎么拿?(免抓包,约 30 天有效)
方式一:免抓包验证码登录(推荐)
在电脑上下载本仓库的 login_helper.py,运行:
python login_helper.py
# 浏览器打开 http://127.0.0.1:8787
拖动官方滑块 → 收短信填验证码 → 登录成功后页面显示 token,复制粘贴到上面即可。 方式二:一次抓包(备选)
用 Stream(iOS)/ Reqable(安卓)抓九号 App 签到页,搜 api/user-sign/v2/sign,取请求头 Authorization 里的 eyJ... 部分(不要带 Bearer)。
🤖 怎么让它每天全自动?(GitHub Actions)
1. Fork / 推送本仓库到 GitHub(可设为 Private)
2. 仓库 Settings → Secrets and variables → Actions → New repository secret
   名称 NINEBOT_ACCOUNTS,值:
[{"name":"主号","token":"eyJ...","deviceId":""}]
3. Actions 页面手动跑一次 ninebot-checkin 验证,之后每天北京时间 9 点左右自动签到
4. (可选)再加一个 secret BARK_KEY,签到结果推送到手机
🔐 隐私与说明
• token 只保存在你自己的浏览器 localStorage(或 GitHub Secrets),本页面无任何服务器、无统计
• 所有请求直接发往九号官方:cn-cbu-gateway.ninebot.com(签到)、api.day.app(可选推送)
• token 约 30 天过期,页面会在到期前 3 天标红提醒,过期后用 login_helper.py 重新获取
• 个人自动化工具,请自行评估与平台条款的冲突,请勿用于商业用途
